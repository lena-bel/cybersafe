# CyberSafe 🔐

**Stay informed. Stay protected. Stay safe.**

CyberSafe is an educational website designed to raise awareness about cybersecurity and encourage safer online habits. It provides practical security tips and interactive features to help users better understand how to protect their personal information and digital devices.

## 🌐 About the Project

CyberSafe was developed as part of a JavaScript web development project. The goal is to make cybersecurity information accessible through a simple, interactive and user-friendly website.

The website consists of two main pages:

- **Home:** Introduces cybersecurity topics and provides useful security tips.
- **Security Check:** Allows users to share information about their digital habits through an interactive form.

## ✨ Features

### 🏠 Homepage

- **Cybersecurity tips:** Discover practical advice about passwords, phishing, online privacy and device protection.
- **Interactive search:** Search for security tips using keywords.
- **Dynamic results:** Display matching tips and update the number of search results.
- **Add new tips:** Create and display new cybersecurity tips dynamically.
- **Local storage:** Keep user-added tips after refreshing the page.
- **Current date:** Automatically display the current date.

### 🛡️ Security Check Form

- Personal information fields.
- Two synchronised dropdown lists for device selection.
- Operating system selection using radio buttons.
- Security habits selection using checkboxes.
- Additional comments field.
- JavaScript form validation with error and success messages.


**2. Open the project**

Open `index.html` using the Live Server extension.

**4. Explore CyberSafe**

Navigate through the homepage and Security Check form to test the available features.

## 🔒 Privacy

CyberSafe is a front-end educational project.

- No backend server is used.
- Form information is not transmitted to an external server.
- User-created tips are stored locally in the browser using localStorage.
